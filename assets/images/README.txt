Put your own photos/videos in this folder and reference them in the Media
sheet as e.g.  assets/images/about.jpg  — relative paths are resolved
correctly on every page, including product pages. The shipped about.jpg is
a GREEN test image so you can visually confirm the Excel->website pipeline:
set about_image Image URL = assets/images/about.jpg, run the updater,
upload site.js, hard-refresh -> the About photo turns green. Then replace
this file with your real photo (keep the same name, or update the sheet).
